## 規則與時間

- 買進：前棒 Close <= 前棒 MA60，且當棒 Close > 當棒 MA60。
- 賣出：前棒 Close >= 前棒 MA60，且當棒 Close < 當棒 MA60。
- 精確比較，不加容忍值、過濾條件、持倉去重或其他指標。
- 當棒相等不產生訊號；前棒相等而當棒嚴格穿越可產生訊號。
- 訊號只標記穿越當根。持續位於同側不重複觸發。
- 比較完整時間格的相鄰兩根；不先刪除缺漏或無效棒，也不把暖身第一個 MA 點當成穿越。
- 兩根各自都須有有效已收盤棒與有效 MA60，正常情況最早第 61 根可判斷。
- 13:00～13:30 短棒仍計一根，於 13:30 才可成立訊號。
- bar_start 是 K 棒開始時間；signal_time 等於 bar_end，是收盤後可判斷時間。
- 訊號不代表成交或部位；本階段沒有資金、損益或績效回測。

## 執行方式

在台股目錄：

~~~powershell
python -B -X utf8 -m 666_strategy 2330.TW 2408.TW --signals --ca-bundle 666_strategy/.cache/windows_current_roots.pem --output 666_strategy/verification/signals_live_20261026.json
~~~

~~~powershell
python -B -X utf8 -m unittest discover -s 666_strategy/tests -v
~~~

