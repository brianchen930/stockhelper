# 666_strategy：日線多頭改為「MA60 > MA120」（六檔，2024-10-30～2026-10-29）

完成日期：2026-11-16。隔離實驗，**未修改** daily.py；以已驗證的日線資料重算多頭狀態。A 組六檔精確重現既有結果。

## 定義

- 原多頭（A）：日線 Close > MA60、MA60 > MA120、MA60 高於 5 個交易日前，三項同時成立。
- 新多頭（N 系列）：**日線 MA60 > MA120**（使用者確認）。暖身不足或資料衝突仍視為 UNKNOWN，不會進場。
- 進場不變：日線多頭時，60 分 K 收盤價由下往上穿過 60 分 MA60，下一根 K 開盤買進。KD 不參與進出場。

| 組別 | 多頭定義 | 60分 MA60 跌破 | 日線轉非多頭出場 | 高檔爆量出場 |
|---|---|:-:|:-:|:-:|
| A | 原三條件 | ✓ | ✓ | |
| N | MA60>MA120 | ✓ | ✓ | |
| N2 | MA60>MA120 | ✓ | | |
| N3（你描述的完整操作） | MA60>MA120 | ✓ | | ✓ |

## 解讀

1. **新定義讓 6 檔中 5 檔報酬提高**（只有 3211 下降）。主因是條件放寬，可進場的天數大幅增加，例如 2454 從 41% 提高到 69%，持倉時間變長，吃到更多漲幅。
2. **代價是交易次數、費稅和回撤都增加**。六檔中有五檔最大回撤升高，2454、6147、3211 約多 10～15 個百分點。
3. **拿掉日線出場（N2）在 6147、3211 更好，其餘四檔不變**。新定義下日線轉非多頭較晚發生，出場時常已經跌了一段；既然 60 分 MA60 跌破通常先觸發，只看 MA60 出場即可。
4. **加上高檔爆量出場（N3）在 5 檔明顯變差**，結論和上一輪相同：在這段多頭裡，這個訊號多數出現在主升段途中。
5. **六檔仍全部落後買進持有**，2408 差距最大（283% 對 1010%）。

## 結論

在這個樣本中，日線多頭改成「MA60 > MA120」，再搭配只用 60 分 MA60 跌破出場（N2），是目前測過最好的組合：六檔都不比原策略差，且 5 檔更好。不過回撤也變大，而且期間只涵蓋多頭，仍需要包含空頭的資料來驗證。
